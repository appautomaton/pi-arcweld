# Website ownership

The public website remains at https://appautomaton.com/pi-arcweld/.

Edit its independent HTML, styles, scripts, and assets in
[the frontend module](https://github.com/appautomaton/appautomaton.github.io/tree/main/sites/pi-arcweld). The App Automaton frontend repository builds,
checks, and publishes this route together with its discovery files.

This repository owns the Pi workspace, extensions, runtime, and technical
instructions. Its former `docs/` website and Pages workflow have been retired.
Website link and asset checks now run in the frontend build.
